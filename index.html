Хто створює сайт?

  • Frontend

    Перетворює дизайн-макет на живу сторінку: верстка, стилі, інтерактивність.

    Що робить фронтенд розробник?
    • - Верстає сторінки за макетом
    • - Підключає стилі та скрипти
    • - Робить адаптив під mobile

  • UI/UX дизайн

    Проєктує структуру сторінки та вигляд інтерфейсу.

    Що передає фронтенд розробнику?
    • - Макет Desktop і mobile
    • - Дизайн систему
    • - Стани кнопок і форм

  • QA тестувальник

    Перевіряє сайт на помилки та слідкує, щоб усе працювало як треба.

    Що робить QA?
    • - Пише тест-кейси
    • - Знаходить баги та оформлює звіти
    • - Перевіряє форми та посилання

  • Project manager

    Керує командою, планує задачі та слідкує за дедлайнами.

    Що робить PM?
    • - Розподіляє задачі між учасниками
    • - Проводить зустрічі та стендапи
    • - Контролює терміни та результат

  • Backend

    Створює серверну частину: логіку, бази даних та API.

    Що робить бекенд розробник?
    • - Пише серверну логіку
    • - Працює з базами даних
    • - Створює API для фронтенду

  • DevOps

    Налаштовує розгортання, сервери та автоматизацію процесів.

    Що робить DevOps?
    • - Налаштовує CI/CD
    • - Керує серверами та контейнерами
    • - Автоматизує деплой
